Quel iPhone ai-je? Recherchez-le par numéro de modèle

App Store Télécharger

Avant d'acheter ou de vendre un téléphone usagé ou de choisir des accessoires, confirmez le modèle. Apple tient une liste que vous pouvez consulter par numéro de modèle.

1. Trouvez le numéro de modèle

Trouvez le numéro de modèle de votre iPhone en suivant l'article distinct d'Apple; sur les modèles plus anciens, comme l'iPhone 7, il est imprimé sur le couvercle arrière.

2. Comparez-le dans la liste d'Apple

Le répertoire « Identifier le modèle de votre iPhone » d’Apple indique, pour chaque modèle, l’année, la capacité, les couleurs et les numéros de modèle selon la région, de sorte que le numéro de modèle permet de trouver le modèle exact.

La page Matériel d’Inside affiche les informations en temps réel de l’appareil en indiquant leur source, et son explorateur 3D présente l’apparence de votre modèle d’iPhone. App Store

Sources: support.apple.com/en-us/108044 · support.apple.com/en-us/106343
