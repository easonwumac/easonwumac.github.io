Identifier une plante à partir d’une photo avec la fonction Recherche visuelle de l’iPhone

App Store Télécharger

Vous ne savez pas comment s’appelle votre plante d’intérieur? La fonction Recherche visuelle de l’iPhone peut identifier les plantes et les fleurs sur une photo.

1. Sélectionner la photo

Dans une app comme Notes, Mail ou Messages, maintenez le doigt sur l’image, puis touchez le bouton Info (dans Safari, touchez Rechercher). L’iPhone doit fonctionner sous iOS 15 ou une version ultérieure.

2. Touchez l’icône de feuille

Appuyez sur l’icône de feuille sur ou sous la photo pour voir les résultats de Siri Knowledge et du Web. Si le bouton « Info » ne présente pas d’étoile, Visual Look Up n’est pas disponible pour cette photo.

ZaiRi est un journal de plantes : photographiez la croissance, identifiez les plantes à partir de photos, consignez rapidement les arrosages et les fertilisations, et recevez des rappels pour les tâches d’entretien. Toutes les fonctions du journal sont gratuites. App Store
