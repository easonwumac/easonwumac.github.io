iPhone 측정 앱으로 사람의 키를 재는 방법은?

지원되는 기기에서 '측정기' 기능으로 사람의 키를 자동으로 잴 수 있어요: 인물이 머리부터 발끝까지 화면에 완전히 들어오도록 한 다음, 머리 위에 측정선이 나타날 때까지 기다렸다가 결과를 촬영하세요. 모자도 키에 포함되어 계산돼요.

1. 기능 지원 여부 확인하기

Apple은 키 자동 측정 기능을 지원되는 기종으로 한정합니다. 기기에 측정 앱이 있다고 해서 키를 자동으로 인식할 수 있다고 단정할 수는 없습니다.

2. 전신이 화면에 모두 들어오게 하기

「측정」 앱을 열고 iPhone을 조정해 측정할 사람의 머리부터 발끝까지 화면에 보이도록 하세요. 자동 감지될 때까지 기다리세요.

3. 측정 상단 지점 정확히 읽기

측정선은 머리, 머리카락 또는 모자의 꼭대기에 표시되며, 수치는 측정선 아래에 나타납니다. 모자를 쓰고 있으면 표시되는 높이에 모자가 포함됩니다.

4. 결과 저장 또는 다시 측정하기

촬영 버튼을 누르면 측정 이미지가 저장됩니다. 다시 측정하려면 iPhone을 잠시 다른 방향으로 돌렸다가 사람에게 다시 향하게 하면 키 측정이 초기화됩니다.

5. 앉은 키도 측정할 수 있어요

Apple 설명에서도 앉은 키 측정을 지원해요. 위쪽 선이 머리, 머리카락, 모자 중 어디에서 끝나는지 확인하세요.
