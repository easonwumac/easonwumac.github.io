Enregistrer les captures d'écran de l'iPhone directement : désactiver l'aperçu plein écran

Vous ne voulez pas passer en plein écran à chaque capture ? Désactivez « Aperçus plein écran » pour revenir à une petite vignette dans le coin inférieur gauche. Les captures en mode vignette sont enregistrées automatiquement dans Photos.

1. Trouver les réglages de capture d'écran

Allez dans Réglages > Général > Capture d'écran pour modifier l'affichage de l'aperçu de capture d'écran.

2. Désactiver les aperçus plein écran

Désactivez « Aperçus plein écran ». Les futures captures d'écran s'afficheront alors sous forme de vignettes temporaires dans le coin inférieur gauche.

3. Laissez la vignette disparaître

Le mode vignette enregistre automatiquement les captures d'écran ; touchez la vignette seulement lorsque vous voulez la modifier. iOS 18 et les versions antérieures affichent aussi une vignette dans le coin inférieur gauche.

4. Enregistrez depuis la vue plein écran

Lorsque les aperçus plein écran sont activés, vous pouvez annoter, recadrer ou partager la capture d'écran. Utilisez le bouton d'enregistrement pour choisir où la conserver.

5. Repérer les captures d'écran enregistrées

Retrouvez les captures enregistrées dans Photos > Collections > Types de médias > Captures d'écran.

Tuck peut éventuellement enregistrer les nouvelles captures d'écran lorsque vous ouvrez l'application.
