아이폰 스크린샷 바로 저장: 전체 화면 미리보기 끄기

전체 화면 미리보기를 끄면 왼쪽 아래의 작은 썸네일로 돌아갑니다. 썸네일 모드에서 찍은 스크린샷은 자동으로 사진 앱에 저장됩니다.

1. 스크린샷 캡처 설정 찾기

"설정" > "일반" > "스크린샷 캡처"로 이동하세요. 여기서 스크린샷 미리보기 표시 방식을 바꿀 수 있습니다.

2. 전체 화면 미리보기 끄기

「전체 화면 미리보기」를 끄면 이후 스크린샷이 왼쪽 아래에 잠깐 나타나는 축소 썸네일로 표시됩니다.

3. 스크린샷 후 썸네일이 사라지도록 두기

썸네일 모드에서는 스크린샷이 자동으로 저장됩니다. 편집하고 싶을 때만 썸네일을 엽니다. iOS 18 이하 버전도 왼쪽 아래 썸네일을 사용합니다.

4. 전체 화면 보기에서 직접 저장하기

전체 화면 미리보기를 켜 두면 스크린샷에 표시를 하거나, 자르거나, 공유할 수 있습니다. 저장 버튼을 눌러 저장 위치를 선택하세요.

5. 선택 목록에서 저장된 스크린샷 찾기

「사진」>「선택 목록」>「미디어 유형」>「스크린샷」에서 저장된 캡처를 확인하세요.

Tuck은 앱을 열 때 새 스크린샷을 선택적으로 자동 저장할 수 있습니다.
