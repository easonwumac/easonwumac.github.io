Comment trouver le numéro de série d'un iPhone sans deviner

Le numéro de série d'un iPhone se trouve dans « Informations », et pour un téléphone pas encore configuré, vous pouvez le consulter sur l'écran « Bonjour » en appuyant sur le bouton d'information. Si le téléphone n'est pas à portée de main, vous pouvez vérifier l'emballage d'origine ou votre compte Apple.

1. Chercher dans Réglages

Ouvrez Réglages > Général > Informations et repérez « Numéro de série ». L'IMEI et l'EID sont des identifiants distincts; vérifiez donc le champ que vous copiez.

2. Copier plutôt que retaper

Pour un formulaire d’assistance Apple, maintenez le numéro enfoncé pour le copier, puis collez-le dans le champ correspondant.

3. Vérifier avant la configuration

À l’écran « Bonjour » multilingue au démarrage, touchez le bouton d’information dans le coin inférieur droit pour afficher les identifiants de l’appareil.

4. Utilisez l’emballage ou votre compte

Le numéro de série se trouve sur l’étiquette à code-barres de la boîte d’origine. Vous pouvez aussi vous connecter à account.apple.com avec l’identifiant Apple utilisé sur ce téléphone, puis le sélectionner sous Appareils.

5. Vérifier depuis un ordinateur

Une fois le téléphone connecté à l’ordinateur, sur Mac, ouvrez le Finder, sélectionnez l’appareil, assurez-vous d’être dans l’onglet « Général » et cliquez sur le nom du modèle sous le nom de l’appareil pour afficher le numéro de série. Sous Windows, utilisez la dernière version de l’app « Appareils Apple » ou iTunes.

La vérification du numéro de série dans Inside utilise les informations que vous saisissez après les avoir consultées dans « Réglages », et le rapport les indique comme saisies par l’utilisateur.

Gratuit sur l’App Store
