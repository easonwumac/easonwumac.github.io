Comment trouver les forums PTT sur iPhone et conserver ses favoris

Dans Folkline, trouvez les forums PTT par domaines d’intérêt, par catégories de forums ou par recherche approximative du nom. Utilisez les favoris pour vos lectures régulières et les forums récents pour retrouver ceux que vous avez consultés.

1. Parcourez par domaine si vous ne connaissez pas le nom

Folkline regroupe les sujets populaires et les forums populaires par domaine : actualités, sports, investissement, technologie, jeux vidéo et anime, etc. Choisissez d’abord le domaine qui vous correspond; vous saurez ensuite quel forum consulter, ce qui est plus efficace que de deviner le nom du forum.

2. Recherchez si vous connaissez une partie du nom

Le texte de la fiche de l’App Store mentionne la recherche floue par nom de forum. Lorsque vous connaissez un indice sur le nom, utilisez la recherche par nom pour trouver le forum ; cette fonction vise les noms de forums, ne la confondez pas avec la recherche dans le contenu des posts.

3. Explorer les catégories de forums

Les catégories de forums offrent une autre façon de parcourir le contenu, en complément des forums populaires. Choisissez le point d’entrée qui correspond à votre démarche : explorer un sujet ou revenir vers une communauté que vous connaissez déjà.

4. Garder vos forums habituels dans les favoris

La fiche de l’App Store mentionne la fonction « Mes favoris ». Placez-y les forums que vous suivez au quotidien, puis accédez-y depuis les favoris, afin de séparer votre liste habituelle des forums que vous découvrez.

5. Revenir via les forums récents

Utilisez les forums récents lorsque vous ne vous souvenez plus du nom d’un forum que vous venez de consulter. Sur iPad, le mur des forums affiche également plusieurs forums et fils en direct côte à côte.

Folkline propose des sujets populaires regroupés par thème, une recherche tolérante des noms de forums, des favoris et les forums récemment consultés.

Gratuit sur l’App Store
