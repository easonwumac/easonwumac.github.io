iPhone이 업데이트 확인을 할 수 없을 때는 어떻게 하나요?

같은 네트워크에서 다시 시도한 후, 다른 네트워크로 바꿔 보세요. 그래도 실패하면 다운로드된 업데이트를 삭제하고 다시 받거나, 컴퓨터를 이용해 업데이트하세요.

1. 먼저 백업하고 호환성을 확인하세요

업데이트 전에 먼저 백업하세요. 기기가 해당 버전을 지원해야 하며, 인터넷 연결과 충분한 저장 공간이 필요합니다. 업데이트하는 동안에는 휴대폰을 전원에 연결된 상태로 유지하세요.

2. 다시 시도한 뒤 네트워크를 바꾸세요

지금 같은 네트워크에서 다시 업데이트하세요. 여전히 확인 또는 인증을 할 수 없다는 메시지가 나타나면, 다른 네트워크로 바꾸거나 Mac 또는 iTunes를 사용하세요.

3. 다운로드된 업데이트 찾기

설정 > 일반 > iPhone 저장공간으로 이동한 뒤, 목록에서 업데이트 항목을 찾아 열고 '업데이트 삭제'를 선택하세요.

4. 다시 다운로드

설정 > 일반 > 소프트웨어 업데이트로 돌아가 다시 다운로드하세요. Wi-Fi를 사용하고, 다운로드하는 동안에는 다른 콘텐츠를 동시에 다운로드하지 마세요.

5. 업데이트 파일을 찾을 수 없거나 다시 실패하는 경우

저장 공간 목록에 업데이트 파일이 없거나, 다시 받은 뒤에도 문제가 재현되면 Apple의 컴퓨터 업데이트 안내에 따라 Mac 또는 iTunes를 사용하세요.
