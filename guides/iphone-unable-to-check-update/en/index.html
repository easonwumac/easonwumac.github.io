iPhone unable to check for an update?

Retry on the same network, then try a different one. If it still fails, remove the downloaded update and download it again, or update using a computer.

1. Back up and check compatibility

Back up first. The update requires a compatible device, internet access, and enough storage. Keep the phone connected to power.

2. Retry, then switch networks

Retry on the same network. If checking or verification still fails, try another network, a Mac, or iTunes.

3. Find the downloaded update

Open Settings > General > iPhone Storage. Find the update in the list, open it, and choose Delete Update.

4. Download it again

Return to Settings > General > Software Update and download again. Use Wi-Fi and avoid other downloads while it runs.

5. If there is no update file

If the update is absent from storage or fails again, follow Apple’s instructions for updating with a Mac or iTunes.
