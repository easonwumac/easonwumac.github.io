Face ID ne fonctionne pas ? Dépannage étape par étape

Quand Face ID ne vous reconnaît pas, c’est généralement que la caméra est couverte ou que l’angle est incorrect. Suivez l’ordre recommandé par Apple et envisagez la réparation en dernier recours.

1. Vérifiez les réglages

Mettez d’abord iOS à jour vers la dernière version, puis allez dans Réglages > Face ID et code pour confirmer que Face ID est configuré et que les fonctions souhaitées sont activées.

2. Ne bloquez pas la caméra TrueDepth

Assurez-vous que vos doigts, un étui ou un protecteur d'écran ne couvrent pas la caméra TrueDepth; gardez vos yeux, votre nez et votre bouche visibles et tenez le téléphone à environ un bras de distance. Ajoutez une apparence alternative si votre apparence change.

3. Redémarrer ou réinitialiser

Redémarrez, entrez votre code d'accès et réessayez. Si cela échoue encore, allez dans Réglages > Face ID et code, puis Réinitialiser Face ID et configurez-le à nouveau ; si la configuration continue d'échouer, il pourrait être nécessaire de le faire réparer.

Inside inclut Face ID ou Touch ID dans ses vérifications étape par étape et conserve le résultat dans le rapport avec le reste du matériel, afin qu'un acheteur ou un vendeur puisse le vérifier. Les vérifications de base sont gratuites.

Gratuit sur l’App Store

Sources: support.apple.com/en-us/118243
