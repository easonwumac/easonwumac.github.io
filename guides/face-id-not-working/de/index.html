Face ID funktioniert nicht? Der Reihe nach beheben

Wenn Face ID dich nicht erkennt, liegt es meist daran, dass die Kamera verdeckt ist oder der Winkel nicht stimmt. Halte dich an Apples Reihenfolge und ziehe eine Reparatur erst zuletzt in Betracht.

1. Einstellungen prüfen

Aktualisiere zuerst auf die neueste Version von iOS und prüfe dann unter „Einstellungen“ > „Face ID & Code“, ob Face ID eingerichtet ist und die gewünschten Funktionen aktiviert sind.

2. TrueDepth-Kamera freihalten

Stelle sicher, dass Finger, eine Hülle oder eine Displayschutzfolie die TrueDepth-Kamera nicht verdecken; Augen, Nase und Mund müssen vollständig sichtbar sein, und halte das Telefon etwa eine Armlänge entfernt. Wenn sich dein Aussehen deutlich verändert, füge ein alternatives Erscheinungsbild hinzu.

3. Neu starten oder zurücksetzen

Starten Sie neu, geben Sie Ihren Code ein und versuchen Sie es erneut. Wenn es weiterhin nicht klappt, gehen Sie zu Einstellungen > Face ID & Code > Face ID zurücksetzen und richten Sie es erneut ein; wenn die Einrichtung immer wieder scheitert, muss das Gerät möglicherweise repariert werden.

Inside nimmt Face ID bzw. Touch ID in die schrittweisen Prüfungen auf und speichert das Ergebnis zusammen mit der übrigen Hardware im Bericht, sodass Käufer oder Verkäufer es überprüfen können. Die Grundprüfungen sind kostenlos.
