Face ID 認不出你時，多半是相機被擋住或角度問題。照 Apple 的順序檢查，最後才考慮送修。

1. 確認設定已開啟

先更新到最新版 iOS，再到「設定」>「Face ID 與密碼」確認已完成設定，要用的功能也已開啟。

2. 不要擋住原深感測相機

確認手指、保護殼或螢幕保護貼沒有擋住原深感測相機；眼睛、鼻子和嘴巴要完全露出，臉和手機保持約 25 至 50 公分。外觀明顯改變時可以設定另一種容貌。

3. 重新啟動或重置

重新啟動、輸入密碼後再試。仍不行就到「設定」>「Face ID 與密碼」>「重置 Face ID」重新設定；如果一直無法完成設定，可能需要維修。

Face ID not working? Troubleshoot in order

When Face ID won't recognize you, the camera is usually covered or the angle is off. Follow Apple's order and consider repair last.

1. Check the settings

Update to the latest iOS, then check Settings > Face ID & Passcode to confirm Face ID is set up and the features you want are on.

2. Keep the TrueDepth camera clear

Make sure fingers, a case or a screen protector aren't covering the TrueDepth camera; keep your eyes, nose and mouth visible and hold the phone about an arm's length away. Add an alternate appearance if your look changes.

3. Restart or reset

Restart, enter your passcode and try again. If it still fails, go to Settings > Face ID & Passcode > Reset Face ID and set it up again; if setup keeps failing, it may need service.
