Face ID が使えない？順番に確認しましょう

Face ID があなたを認識しないとき、多くはカメラが覆われているか角度がずれていることが原因です。Apple の順序に従ってチェックし、修理は最後に検討してください。

1. 設定がオンになっているか確認する

まず iOS を最新版に更新し、「設定」＞「Face ID とパスコード」で Face ID の設定が完了していて、使いたい機能がオンになっているか確認してください。

2. TrueDepth カメラを覆わないようにする

顔の認証で、指、保護ケース、画面保護フィルムがTrueDepthカメラを覆っていないか確認してください。目、鼻、口は完全に見える状態にし、顔と端末は約25〜50cm離してください。外見が大きく変わった場合は、別の外見を追加できます。

3. 再起動またはリセット

再起動し、パスコードを入力してからもう一度お試しください。それでも失敗する場合は、「設定」>「Face ID とパスコード」>「Face ID をリセット」の順に進んで再設定してください。設定がどうしても完了しない場合は、修理が必要かもしれません。

Inside では、ステップごとのチェックに Face ID または Touch ID を含め、その結果をほかのハードウェアの項目とともにレポートに残すため、買い手や売り手が確認できます。基本チェックは無料です。
