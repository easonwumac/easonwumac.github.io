Face ID 无法使用怎么办？按顺序排查

App Store 下载

Face ID 认不出你时，多半是摄像头被挡住或角度有问题。请按照 Apple 的顺序检查，最后才考虑送修。

1. 确认设置已开启

先更新到最新版 iOS，再到“设置”>“Face ID 与密码”确认已完成设置，并且要使用的功能也已开启。

2. 不要挡住原深感应摄像头

确认手指、保护壳或屏幕保护膜没有挡住原深感摄像头；眼睛、鼻子和嘴巴要完全露出，脸和手机保持约 25 至 50 厘米。外观明显改变时可以设置另一种容貌。

3. 重新启动或重置

重新启动、输入密码后再试。仍不行就到“设置”>“Face ID 与密码”>“重置 Face ID”重新设置；如果一直无法完成设置，可能需要维修。

机况 Inside 会把 Face ID 或 Touch ID 列入逐项检查，结果和其他硬件一起保存在报告里，买卖二手机时可以给对方核对。基本检查免费。 App Store
