Face ID가 작동하지 않나요? 순서대로 문제를 해결하세요

Face ID가 나를 인식하지 못할 때는 대개 카메라가 가려졌거나 각도가 맞지 않은 경우입니다. Apple의 순서를 따르고, 수리는 마지막으로 고려하세요.

1. 설정 확인하기

먼저 iOS를 최신 버전으로 업데이트한 다음, '설정' > 'Face ID 및 암호'에서 Face ID 설정이 완료되었고 사용하려는 기능이 켜져 있는지 확인하세요.

2. TrueDepth 카메라를 가리지 않도록 하기

손가락, 케이스 또는 화면 보호필름이 TrueDepth 카메라를 가리지 않는지 확인하세요. 눈, 코, 입이 보이도록 하고, 휴대폰을 팔 길이 정도 떨어뜨려 들고 계세요. 외모가 많이 바뀌었다면 대체 외모를 추가하세요.

3. 재시동 또는 재설정

재시동한 뒤 암호를 입력하고 다시 시도하세요. 그래도 안 되면 설정 > Face ID 및 암호 > Face ID 재설정으로 가서 다시 설정하세요. 설정이 계속 실패하면 수리가 필요할 수 있습니다.

Inside는 단계별 점검에 Face ID 또는 Touch ID를 포함하며, 결과를 다른 하드웨어와 함께 보고서에 저장하므로 구매자나 판매자가 확인할 수 있습니다. 기본 점검은 무료입니다.
