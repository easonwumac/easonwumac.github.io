¿Face ID no funciona? Resuélvelo siguiendo el orden

Cuando Face ID no te reconoce, normalmente la cámara está tapada o el ángulo no es el correcto. Sigue el orden que indica Apple y considera la reparación al final.

1. Verifica la configuración

Actualiza primero a la versión más reciente de iOS y luego ve a Ajustes > Face ID y código para confirmar que Face ID esté configurado y que las funciones que quieres usar estén activadas.

2. No tapes la cámara TrueDepth

Asegúrate de que los dedos, una funda o un protector de pantalla no tapen la cámara TrueDepth; mantén los ojos, la nariz y la boca visibles y sostén el teléfono a una distancia aproximada de 25 a 50 centímetros. Si tu apariencia cambia de forma notable, puedes configurar una apariencia alternativa.

3. Reiniciar o restablecer

Reinicia el equipo, introduce tu código de acceso y vuelve a intentarlo. Si sigue sin funcionar, ve a Ajustes > Face ID y código > Restablecer Face ID y configúralo de nuevo; si la configuración sigue fallando, es posible que necesite servicio técnico.

Inside incluye Face ID o Touch ID en sus revisiones paso a paso y guarda el resultado en el informe junto con el resto del hardware, de modo que quien compra o vende puede verificarlo. Las revisiones básicas son gratuitas.
