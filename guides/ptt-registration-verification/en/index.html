Does a new PTT account need verification? Registration vs account verification

Creating a PTT account and verifying it are separate stages. The station's announcement allows registration with any email address, but a nontrusted address serves as contact information and does not complete verification.

1. Separate registration from verification

PTT's 2021 announcement opened registration to any email address while distinguishing trusted and nontrusted addresses. Receiving contact email does not by itself establish that account verification is complete.

2. Open account verification when needed

The announcement directs users with nontrusted email addresses to (U)ser personal settings > (R)egister account verification. These are PTT terminal commands, not iPhone Settings menus.

3. Follow the verification options currently offered

The announcement lists trusted email, AOTP mobile verification, and manual review in specified circumstances. It is an older announcement; follow the options actually offered by the station rather than assuming every historical option remains available.

4. AOTP requires an outgoing text

PTT describes AOTP as an outgoing text to a specified short code that verifies the SIM number and code together. If offered, use the current screen's destination and message and read its terms and charges first.

5. Sign in again and use the appropriate help board

PTT's AOTP tutorial says to sign in again after verification. It directs verification questions to SYSOP, command and operation questions to PttNewhand, and BBS software questions to AppsForBBS.
