PTT 계정을 새로 만든 후에도 인증이 필요한가요? 가입과 계정 인증의 차이

PTT 가입과 계정 인증은 서로 다른 단계입니다. 사이트 공지는 어떤 이메일 주소로든 가입할 수 있도록 허용하지만, 신뢰되지 않은 주소는 연락처 정보로만 사용되며 사이트에서 제공하는 방법에 따라 인증을 따로 완료해야 합니다.

1. 가입과 인증을 먼저 구분하세요

PTT는 2021년 공지에서 어떤 이메일 주소로든 가입할 수 있도록 허용했습니다. 이 공지는 신뢰 이메일과 비신뢰 이메일을 구분하고 있으므로, 연락처 이메일을 받았다고 해서 모든 계정 권한이 열린 것으로 보면 안 됩니다.

2. 필요할 때 계정 인증 영역으로 들어가세요

공지에 따르면 비신뢰 이메일 주소를 사용하는 사용자는 연락처 이메일로 설정되며, 이후 "(U)ser 개인 설정 영역" > "(R)egister 계정 인증"으로 이동합니다. 이는 PTT 터미널 텍스트 인터페이스의 경로이며, iPhone "설정" 메뉴가 아닙니다.

3. 인증 방식은 사이트에서 현재 제공하는 옵션을 따르세요

이 공지는 신뢰 이메일, AOTP 휴대폰 인증, 그리고 특정 상황에서의 수동 검토를 나열합니다. 이 공지는 오래된 것이므로, 실제 사용 가능한 방법은 사이트에 현재 표시된 옵션을 기준으로 하고, 표시되지 않은 항목을 예전 튜토리얼대로 선택하지 마세요.

4. AOTP는 사용자가 보낸 문자 메시지가 필요합니다

PTT는 AOTP를 지정된 단축번호로 보내는 발신 문자로 설명하며, 이 방식은 SIM 번호와 인증 코드를 함께 확인합니다. 제공되는 경우, 현재 화면에 표시된 수신 번호와 메시지를 사용하고 먼저 약관과 요금을 읽어 보세요.

5. 완료 후 다시 로그인하고, 문제에 맞는 도움말 게시판을 이용하세요

PTT의 AOTP 튜토리얼은 인증 완료 후 다시 로그인하라고 안내합니다. 계정 인증 문제는 SYSOP에, 명령어 및 조작 문제는 PttNewhand에, BBS 소프트웨어 문제는 AppsForBBS에 문의하도록 되어 있습니다. 먼저 문제 유형을 구분한 뒤 문의하세요.

Folkline은 PTT 계정으로 댓글, 게시글 및 답글을 지원합니다. PTT 호환 리더이며, PTT의 공식 앱이 아닙니다.
