iPhone에서 전체 페이지 스크린샷을 찍고 저장하는 방법

Safari에서 스크린샷을 찍은 뒤 미리보기 썸네일을 탭하고 '전체 페이지'를 선택하면 화면 밖까지 캡처할 수 있습니다. 오른쪽 이미지를 미리 확인해 필요한 내용이 모두 포함되었는지 확인하세요.

1. 웹페이지 열기

Safari에서 보관하려는 페이지를 여세요. 전체 페이지 스크린샷에 적합한 콘텐츠의 예로 Apple이 제시한 것은 전체 웹페이지입니다.

2. 스크린샷을 찍고 전체 페이지 선택

Face ID 모델에서는 측면 버튼과 볼륨 높이기 버튼을 동시에 누르고 빠르게 뗍니다. iPhone SE에서는 홈 버튼과 측면 버튼을 동시에 누르고 빠르게 뗍니다. 왼쪽 아래의 스크린샷 미리보기를 탭한 다음 전체 페이지를 탭합니다.

3. 미리 보기 및 자르기

미리보기의 오른쪽 캡처를 드래그하여 화면 밖의 내용을 확인하세요. 일부만 필요하면 자르기를 누른 후 핸들을 드래그하여 필요한 부분만 남기세요.

4. "사진"에 저장

전체 화면 스크린샷을 사진 보관함에 저장하려면 위로 스와이프하거나 "선택됨" 버튼을 누른 후 옵션을 선택하세요. 그다음 "사진" > "컬렉션" > "미디어 유형" > "스크린샷"에서 찾을 수 있습니다.

5. Full Page 옵션이 없을 때

Safari에서 웹페이지를 열어 한번 시도해 보세요. Apple은 화면을 넘어가는 콘텐츠에 대한 전체 페이지 캡처를 설명하지만, 모든 앱에서 스크롤 캡처를 보장하지는 않습니다.
