植物的變化很慢，靠記憶很難判斷是變好還是變差。定期拍照、記下照護，問題會更早被發現。

1. 固定角度拍照

同一個位置、同樣角度拍，前後對照才看得出差異。

2. 記下每次照護

澆水、施肥、換盆的日期記下來，之後出狀況時才能回頭找原因。

3. 注意擺放位置的光線

同一種植物在不同位置，長法可能完全不同。

How to keep a plant journal with photos

Plants change slowly, so memory alone can't tell you whether one is improving. Regular photos and care notes help you spot problems earlier.

1. Photograph from the same angle

Use the same spot and angle so before-and-after comparisons show real change.

2. Log every bit of care

Note the dates you water, feed and repot, so you can trace the cause when something goes wrong.

3. Watch the light where it sits

The same plant can grow very differently in different spots.
