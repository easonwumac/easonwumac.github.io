iPhone screen won’t rotate? Check orientation lock first

Turn off Portrait Orientation Lock and try an app such as Safari that supports landscape. Some apps never rotate; if several fail, check Level and restart.

1. Open Control Center

On an iPhone without a Home button, swipe down from the top-right corner. With a Home button, swipe up from the bottom.

2. Disable orientation lock

Make sure Portrait Orientation Lock is off, close Control Center, and turn the phone sideways.

3. Try Safari

Not every app supports rotation. Try Safari or another app that supports landscape instead of relying on one app.

4. Check orientation sensing

Open Measure, tap Level, then rest the phone against an object and rotate it to see whether the reading changes. If Level gets stuck, restart the iPhone.

5. Restart if it remains stuck

Restart if Level is stuck or the screen still will not rotate. Contact Apple Support if the problem continues.
