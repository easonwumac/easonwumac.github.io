買二手 iPhone 要檢查什麼？當面驗機清單

當面交易時只有幾分鐘，照這份順序檢查，就能避開被鎖住的手機、換過的零件與壞掉的功能。

1. 確認已經解除啟用鎖定

開機若出現「iPhone 已鎖定給擁有者」，或設定時要求前一位擁有者的 Apple 帳號，代表手機還綁在對方帳號上。Apple 建議在手機從前一位擁有者的帳號移除之前，不要接手。最好請賣家當面清除手機，並確認回到「哈囉」設定畫面。

2. 看零件與維修紀錄

到「設定」>「一般」>「關於本機」查看零件與維修紀錄。標示「未知的零件」可能代表非原廠或未完成驗證的維修零件，會影響轉售價值。

3. 看電池健康度

到「設定」>「電池」>「電池健康度」查看最大容量。這是相對全新時的容量；數字偏低代表續航會變短，議價時可以列入考量。

4. 逐項試功能

  • 螢幕：純色畫面下找亮點、暗點與烙印。
  • 觸控：整片螢幕都要能拖曳，邊角也要有反應。
  • 每顆鏡頭、揚聲器與每個麥克風都要試錄試播。
  • Face ID 或 Touch ID、Wi-Fi、藍牙與充電。

機況 Inside 免費提供逐項檢查與 2 分鐘快速檢查，涵蓋螢幕顯示與觸控、每顆鏡頭、揚聲器、每個麥克風、Face ID 或 Touch ID、感測器、Wi-Fi、藍牙與充電，完成後產生可保存、可分享的報告，方便買賣雙方對照。
