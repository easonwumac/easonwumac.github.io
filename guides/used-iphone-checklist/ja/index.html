中古のiPhoneを買うときに確認すべきこと：対面チェックリスト

手渡し取引では通常、数分しか時間がありません。この順番で確認すれば、ロックされた端末、交換された部品、故障した機能を避けられます。

1. アクティベーションロックが解除されていることを確認する

電源を入れたときに「iPhone はオーナーにロックされています」と表示される場合や、セットアップ中に前の所有者のApple アカウントを求められる場合は、端末がまだ相手のアカウントに紐付いたままです。Appleは、前の所有者のアカウントから端末が削除されるまでは引き継がないよう勧めています。販売者に目の前で端末を初期化してもらい、「こんにちは」のセットアップ画面に戻ることを確認してください。

2. 部品と修理履歴を確認する

設定 > 一般 > 情報 で、部品とサービスの履歴を確認できます。「未知の部品」と表示される場合は、純正ではない、または検証されていない交換部品である可能性があり、下取り価格に影響することがあります。

3. バッテリーの状態を確認する

設定 > バッテリー > バッテリーの状態 で最大容量を確認できます。これは新品時と比べた容量です。数値が低いと駆動時間が短くなるため、価格交渉の際に考慮する価値があります。

4. すべての機能を試す

  • ディスプレイ：単色の画面で、輝点、黒点、焼き付きがないか確認します。
  • タッチ：画面全体でドラッグが機能し、角の部分も反応する必要があります。
  • すべてのカメラ、スピーカー、各マイクで試しに録音・再生してください。
  • Face ID または Touch ID、Wi-Fi、Bluetooth、充電。

Inside は逐項目のチェックと2分のクイックチェックを無料で提供します。画面表示とタッチ、すべてのカメラ、スピーカー、各マイク、Face ID または Touch ID、センサー、Wi-Fi、Bluetooth、充電を対象とし、完了後には保存・共有できるレポートを作成するので、売り手と買い手が照らし合わせやすくなります。
