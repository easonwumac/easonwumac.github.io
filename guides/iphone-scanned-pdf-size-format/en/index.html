Scanned iPhone document too large? Export a smaller PDF or JPEG

Use Preview on iPhone to export a smaller version or a JPEG when needed. Open the exported file and zoom in to check that the text remains readable.

1. Open the existing scan

Open the existing PDF or image in Preview on iPhone. These steps use Preview’s export controls.

2. Open Export

Tap the actions menu beside the filename and choose Export. Select PDF to keep that format, or JPEG for a JPG image.

3. Adjust size options

If a size slider appears, use it to make a smaller file. For JPEG, moving left reduces size and moving right raises quality. Options depend on the format.

For PDF exports offering Optimize Images for Screen, enable it to lower image resolution and reduce size. Save Images as JPEG can also reduce the size of embedded images.

4. Save with a recognizable name

Complete the export using the save options. Choose a location and use the Save As field to give the exported file a distinct name.

5. Check readability and file size

Open the exported file in Preview and zoom in to check that the text is readable before sending it.
