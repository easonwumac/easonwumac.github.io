¿Escaneo de iPhone demasiado grande? Exporta un PDF o JPEG más pequeño

Si ya tienes un escaneo y es demasiado grande, puedes usar Vista previa en el iPhone para exportar una versión más pequeña o cambiarlo al formato JPEG que necesites. Después de exportarlo, amplía el archivo para revisar que el texto se vea bien antes de enviarlo.

1. Abre el escaneo existente

Abre el PDF o la imagen en la app Vista previa del iPhone. Estos pasos usan las opciones de exportación de Vista previa.

2. Abre Exportar

Toca el menú de acciones junto al nombre del archivo y elige Exportar. Selecciona PDF para conservar ese formato, o JPEG para una imagen JPG.

3. Ajustar opciones de tamaño

Si aparece un control deslizante de tamaño, úsalo para obtener un archivo más pequeño. En JPEG, deslizarlo a la izquierda reduce el tamaño y deslizarlo a la derecha aumenta la calidad. Las opciones dependen del formato.

Si la exportación a PDF ofrece «Optimizar imágenes para pantalla», actívala para reducir la resolución de las imágenes y el tamaño del archivo. «Guardar imágenes como JPEG» también puede reducir el tamaño de las imágenes incrustadas.

4. Guardar con un nombre fácil de reconocer

Completa la exportación usando las opciones de guardado. Elige una ubicación y usa el campo "Guardar como" para darle al archivo exportado un nombre distinto.

5. Revisa la legibilidad y el tamaño del archivo

Abre el archivo exportado en Vista Previa y amplía la imagen para comprobar que el texto se lee bien antes de enviarlo.
