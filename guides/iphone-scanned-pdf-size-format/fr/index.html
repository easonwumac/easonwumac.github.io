Votre document numérisé sur iPhone est trop volumineux ? Exportez un PDF ou un JPEG plus petit

Si vos fichiers numérisés existants sont trop lourds, utilisez Aperçu sur iPhone pour exporter une version plus petite ou au format JPEG si nécessaire. Après l'exportation, agrandissez le fichier pour vérifier que le texte est lisible, puis confirmez qu'il est net avant de l'envoyer.

1. Ouvrir le scan existant

Ouvrez le PDF ou l'image existant dans l'app Aperçu sur iPhone. Ces étapes utilisent les commandes d'exportation d'Aperçu.

2. Ouvrir Exporter

Touchez le menu d'actions à côté du nom de fichier et choisissez Exporter. Sélectionnez PDF pour conserver ce format, ou JPEG pour une image JPG.

3. Ajuster les options de taille

Si un curseur de taille apparaît, utilisez-le pour obtenir un fichier plus petit ; pour le JPEG, glisser vers la gauche réduit la taille et glisser vers la droite augmente la qualité. Les options dépendent du format de sortie.

Pour les exportations PDF proposant « Optimiser les images pour l'écran », activez cette option pour réduire la résolution des images et la taille du fichier. « Enregistrer les images en JPEG » peut aussi réduire la taille des images intégrées.

4. Enregistrer avec un nom facile à reconnaître

Terminez l'exportation à l'aide des options d'enregistrement. Choisissez un emplacement et utilisez le champ « Enregistrer sous » pour donner au fichier exporté un nom distinct.

5. Vérifiez la lisibilité et la taille du fichier

Ouvrez le fichier exporté dans Aperçu et effectuez un zoom avant pour vérifier que le texte est lisible avant de l'envoyer.

Tuck importe les fichiers, conserve les originaux et vous permet de rechercher le texte des documents.
