iPhone에서 스캔한 문서 파일이 너무 큰가요? 더 작은 PDF 또는 JPEG로 내보내세요

이미 있는 스캔 파일이 너무 클 때는 iPhone의 "미리보기"로 더 작은 버전을 내보내거나 필요한 경우 JPEG로 변환할 수 있습니다. 내보낸 파일을 열어 확대해서 글자가 선명한지 확인한 후 전송하세요.

1. 기존 스캔 파일 열기

iPhone의 "미리보기" 앱에서 기존 PDF 또는 이미지를 엽니다. 아래 단계는 "미리보기"가 제공하는 내보내기 기능을 사용합니다.

2. 내보내기 열기

파일 이름 옆의 작업 메뉴를 탭한 다음 내보내기를 선택하세요. 해당 형식을 유지하려면 PDF를 선택하고, JPG 이미지를 원하면 JPEG를 선택하세요.

3. 크기 옵션 조정

크기 슬라이더가 나타나면 이를 사용해 더 작은 파일을 만드세요. JPEG의 경우 왼쪽으로 옮기면 크기가 줄고, 오른쪽으로 옮기면 품질이 높아집니다. 옵션은 형식에 따라 다릅니다.

PDF 내보내기에서 "화면용 이미지 최적화"를 제공하는 경우 이를 켜면 이미지 해상도가 낮아지고 파일 크기가 줄어듭니다. "이미지를 JPEG로 저장"도 내장 이미지의 크기를 줄일 수 있습니다.

4. 알아보기 쉬운 파일 이름으로 저장

저장 옵션을 사용해 내보내기를 완료하세요. 위치를 선택하고 '다른 이름으로 저장' 필드에 내보낸 파일의 고유한 이름을 지정하세요.

5. 가독성과 파일 크기 확인

미리보기에서 내보낸 파일을 열고 확대하여 텍스트가 잘 읽히는지 확인한 후 전송하세요.
