How to organize a renovation plan, versions, and backups

Keep the existing room, layout choices, materials, and design versions organized. Roomory supports saved versions, project backups, and review before merging a new scan.

1. Create the existing layout

Scan with LiDAR or create the room manually, including walls, doors, windows, and furniture. Recheck scanned dimensions on site before using the plan.

2. Separate the plan layers

Roomory separates architecture, furniture, and services layers and allows changes to object size, position, and angle. Use these layers to organize proposed changes.

3. Compare materials and daylight

Switch to 3D to try materials and daylight settings, alongside the plan when discussing alternatives.

4. Save design versions

Roomory supports saving design versions as well as project backup and import. When you rescan, check the old and new wall positions before confirming the merge; your existing edits are kept and a version backup is created.

5. Arrange professional review

An organized proposal still needs qualified professional review before construction. Roomory does not provide professional sign-off.

Roomory saves design versions, exports and imports project backups, and syncs through iCloud to keep renovation ideas together.
