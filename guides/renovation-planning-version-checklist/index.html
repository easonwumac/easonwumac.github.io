裝潢規劃表怎麼做？整理方案、版本與備份

自己規劃裝潢時，可把現況、配置、材質與版本分開整理。居圖支援設計版本、專案備份與重新掃描核對，方便保留修改依據。

1. 建立現況方案

以 LiDAR 掃描或手動建立房間，記錄牆面、門窗與家具；掃描尺寸仍需現場複測。這份現況可作為後續配置的起點。

2. 分層整理修改內容

居圖可分開查看建築、家具與設備圖層，並調整物件尺寸、位置及角度；討論時可依這些圖層整理不同修改項目。

3. 比較材質與日照

切換 3D 配置，嘗試不同材質與日照時段；平面圖與 3D 預覽可以一起用於討論方案。

4. 修改後保存版本

居圖支援保存設計版本，以及專案備份與匯入。重新掃描時，先核對新舊牆面位置再確認合併，既有編修會保留並建立版本備份。

5. 交付前安排專業審核

整理好方案不等於完成施工審核。商店明列施工前須由合格專業人員審核圖面，居圖不提供專業簽核。

居圖 Roomory 可保存設計版本、備份與匯入專案，並透過 iCloud 同步，讓裝潢方案與修改紀錄放在同一個專案中。
