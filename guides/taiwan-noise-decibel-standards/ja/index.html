騒音の分貝基準はいくつですか？営業場所、工事現場、拡声設備の対照表

台湾の騒音の分貝基準は、音源、規制区域、時間帯によって異なります。たとえば、第二種規制区域の娯楽施設および営業場所は、昼間57 dB(A)、夕方52 dB(A)、夜間47 dB(A)に制限されています（20 Hz〜20 kHz）。

1. まず音源に対応する表を探す

〈騒音規制基準〉は、工場、娯楽・営業施設、建設工事、拡声設備それぞれの基準を個別に示しています。エアコン設備、工事現場、宣伝車は、どれも騒がしいからといって、同じ行の数値と比較することはできません。

2. 第一種から第四種の管制区を確認する

騒音規制の基準は第一類から第四類までの騒音管制区によって区分されています。表を確認する前に、測定地点がどの管制区に属するかを所在地の環境保護局に確認してください。「ここは住宅地だから」と自己判断で第一類を選んではいけません。

3. 管制区ごとの時間帯を確認する

昼間は午前7時から午後7時までです。夜間の始まりは、第一類と第二類では午後10時、第三類と第四類では午後11時です。その後、翌朝7時までが夜間となります。適切な欄を選ぶ前に時刻を正確に記録してください。

4. 周波数範囲と指標を照合する

表には20Hzから20kHz、20Hzから200Hzなど、さまざまな周波数範囲が設定されています。等価騒音レベル（Leq）は一定時間のエネルギー平均であり、最大騒音レベル（Lmax）は測定期間中の最大値です。スマートフォンに表示される一つのピーク値を、すべての基準の判定値として扱うことはできません。

5. 測定規制の対象かどうかをまず確認する

環境省の説明によると、断続的で測定しにくいものの、生活の静穏を損なう音は警察の管轄となります。このような騒音に遭遇した場合は、スマートフォンで何デシベルを超えているかを先に証明する必要はありません。何がいつ起きたかを説明すればよいのです。

6. 主な基準値（20 Hz〜20 kHz、単位 dB(A)）

〈騒音管理基準〉に基づき、以下は第一種から第四種までの規制区域における昼間／夕方／夜間の基準値です。所在地が特定の規制区域に指定された場合、各基準値は5 dB(A)引き下げられます。

  • 娯楽場所、営業場所：第一種 55／50／40、第二種 57／52／47、第三種 67／57／52、第四種 80／70／65。
  • 工場：第1種 50 / 45 / 40、第2種 57 / 52 / 47、第3種 67 / 57 / 52、第4種 80 / 70 / 65。
  • 建設工事の等価騒音レベル（Leq）：第一類 67／47／47、第二類 67／57／47、第三類 72／67／62、第四類 80／70／65。最大騒音レベル（Lmax）：第一・二類 100／80／70、第三・四類 100／85／75。
  • 拡声設備：第一類 57／47／40、第二類 72／57／47、第三類 77／62／52、第四類 82／72／62。

工場、営業所、建設工事には、20 Hz から 200 Hz までの低周波数の別基準もあり、その数値はより低く設定されています。室内で窓を閉め、規格に適合した一種の騒音計を使って測定します。

Hearscape は地域・時間帯ごとに監視しきい値を設定でき、PDF レポートも出力できます。ストアの説明では、スマートフォンでの測定は参考用であり、検定済みの騒音計によるものではないと明記されています。
