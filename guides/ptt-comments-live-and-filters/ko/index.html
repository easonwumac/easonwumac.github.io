PTT 댓글을 실시간 업데이트, 필터, 알림과 함께 따라가는 방법

Folkline은 활발한 PTT 스레드의 새 댓글을 따라가며, 반응(추천/비추천), 작성자 또는 특정 ID로 필터링할 수 있는 기능을 제공합니다. 나중에 다시 보고 싶다면 게시글을 팔로우해 알림을 받으세요.

1. 게시글과 함께 댓글 읽기

댓글은 채팅 형식의 메시지로 표시되며, 작성자의 댓글은 강조 표시됩니다. 다른 사람의 반응을 해석하기 전에 게시글과 작성자의 추가 설명을 먼저 읽으세요. 댓글 수만으로는 토론 내용을 알 수 없습니다.

2. 필터로 보는 범위 좁히기

긍정, 부정, 또는 중립 댓글, 작성자, 이미지, 또는 특정 ID로 필터링하세요. 업데이트를 보려면 작성자 필터를, 한 참여자의 기여를 따라가려면 ID 필터를 선택하세요.

3. 층수로 긴 스레드 이동하기

상점 설명에는 댓글 추이 차트와 층수 스크러버가 나열되어 있습니다. 긴 스레드에서는 층수 스크러버로 위치를 옮긴 뒤 필터로 읽을 내용을 좁히세요. 새 댓글을 보고 싶다면 토론 스레드의 실시간 업데이트를 확인하세요.

4. 실시간 읽기와 알림을 용도별로 구분해 사용하기

활발한 토론 스레드는 새 댓글을 자동으로 따라갈 수 있습니다. 작성자, 게시글, 키워드를 팔로우하면 새 게시글이나 댓글이 올라왔을 때 알림을 받을 수 있습니다. 스레드를 읽는 중에는 실시간 읽기를, 나중에 다시 확인하려면 알림을 사용하세요.

5. PTT 계정을 사용해 댓글 달기

Folkline의 계정 기능에는 댓글, 게시글, 답글이 포함되며 PTT 계정이 필요합니다. 제출된 내용은 확인을 위해 다시 읽어 표시됩니다. 스레드를 읽는 것과 참여하는 것은 구분하세요.

Folkline은 댓글 필터, 실시간 스레드, 팔로우 알림을 제공합니다. 게시글과 댓글 화면에는 광고가 없습니다.
