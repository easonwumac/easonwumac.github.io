PTT 推文怎么追？自动更新、筛选与通知

在乡民 Folkline 追 PTT 推文，可让热闹讨论串自动跟上新留言，再按推嘘、原 PO 或指定 ID 筛选；想之后再回来看，则使用文章追踪与通知。

1. 在文章里读完整讨论

Folkline 以聊天消息方式呈现推文，原 PO 的推文另外标色。先看文章与原 PO 补充，再读其他人的回应，避免只看推文数就推断讨论内容。

2. 用筛选缩小阅读范围

按正面、负面或中立评论、作者、图片或特定 ID 进行筛选。选择作者筛选以查看更新，或选择 ID 筛选以关注某位参与者的发言。

3. 用楼层滚动定位长串

商店列表列出了推文趋势图与楼层快速滚动。长串可用楼层滚动移动位置，再搭配筛选阅读；需要看新留言时，留意讨论串的实时更新。

4. 实时阅读与稍后通知分开用

热闹的讨论串可自动跟上新推文；追踪作者、文章与关键字，则可在有新文章或新推文时收到通知。前者是在阅读串时跟进，后者是留待之后回来看。

5. 要发推文，使用 PTT 账号

Folkline 的账号功能包含推文、发文与回文，需要 PTT 账号；发送后会自动读回确认。读留言与发送自己的回应，是不同的使用需求。

鄉民 Folkline 支持推文筛选、实时串与追踪通知。文章与推文画面没有广告。
