PTT 推文怎麼追？自動更新、篩選與通知

在鄉民 Folkline 追 PTT 推文，可讓熱鬧討論串自動跟上新留言，再按推噓、原 PO 或指定 ID 篩選；想之後再回來看，則使用文章追蹤與通知。

1. 在文章裡讀完整討論

Folkline 以聊天訊息方式呈現推文，原 PO 的推文另外標色。先看文章與原 PO 補充，再讀其他人的回應，避免只看推文數就推斷討論內容。

2. 用篩選縮小閱讀範圍

可依推、噓、→、原 PO、有圖或指定 ID 篩選。需要找作者補充就看原 PO，需要追某位使用者的發言就指定 ID，選擇對應閱讀目的的條件。

3. 用樓層捲動定位長串

商店列有推文趨勢圖與樓層快速捲動。長串可用樓層捲動移動位置，再搭配篩選閱讀；需要看新留言時，留意討論串的即時更新。

4. 即時閱讀與稍後通知分開用

熱鬧的討論串可自動跟上新推文；追蹤作者、文章與關鍵字，則可在有新文章或新推文時收到通知。前者是在閱讀串時跟進，後者是留待之後回來看。

5. 要發推文，使用 PTT 帳號

Folkline 的帳號功能包含推文、發文與回文，需有 PTT 帳號；送出後會自動讀回確認。讀留言與送出自己的回應，是不同的使用需求。

鄉民 Folkline 支援推文篩選、即時串與追蹤通知。文章與推文畫面沒有廣告。
